# AMASFAC — Comité de Comunicación y Difusión

Sitio estático de una sola página (HTML autocontenido) desplegado en Vercel.

- URL producción: `https://amasfac-comunicacion.vercel.app`
- Fuente: `index.html` (todas las fuentes, imágenes y estilos embebidos como base64)

## Actualizar

1. Reemplazar `index.html` con la nueva versión.
2. `git add index.html && git commit -m "actualizar" && git push`
3. Vercel despliega automáticamente.
